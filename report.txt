Лабораторная работа № 2 посвящена изучению системы контроля версий Git и облачного сервиса GitHub.
Цель работы — получить практический опыт клонирования репозитория, создания коммитов и отправки изменений на сервер.

В ходе работы я освоила создание веток, оформление Pull Request и прохождение ревью кода.
Также были изучены инструменты управления задачами Issues и Projects на платформе GitHub.
Дополнительно я научилась разрешать конфликты слияния при одновременной работе нескольких разработчиков.

Используемые инструменты:
1. Git — распределённая система контроля версий для отслеживания изменений.
2. GitHub Desktop — графический клиент для удобной работы с Git.
3. GitHub — облачная платформа для хостинга репозиториев и совместной разработки.
